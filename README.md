🛒 Walmart Sales Data Analysis
📌 Project Overview

This project focuses on analyzing Walmart sales data to uncover meaningful business insights using Python, Pandas, SQL, and MySQL.

The project follows an end-to-end data analysis workflow, starting from data cleaning and exploratory data analysis (EDA) in Python and extending to business problem-solving using SQL in MySQL Workbench.

The main objective of this project is to understand sales performance, customer behavior, product category performance, payment preferences, branch performance, and profitability.


🎯 Objectives

 - The key objectives of this project are:

- Clean and prepare the raw sales dataset for analysis.
- Perform Exploratory Data Analysis (EDA) using Python.
- Identify sales and revenue trends.
- Analyze category, city, and branch performance.
-Study customer ratings and payment behavior.
-Identify high-value transactions.
-Perform profitability analysis.
-Solve business-driven problems using SQL.

Apply important SQL concepts such as aggregate functions, subqueries, window functions, CTEs, views, and date functions.
